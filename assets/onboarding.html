如何获取 API Key?

在模型服务商官网的控制台获取 API Key，本应用支持 OpenAI 兼容接口（如 OpenAI、DeepSeek、通义千问、Moonshot、智谱等）。

获取后填入输入框，并配置对应的 API 地址与模型名称即可。
